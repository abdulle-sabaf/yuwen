## “逻辑”一词的六大滥用场景及系统替代方案

### 1. 指代“学科、理论或系统性规律”
*   **滥用表现**：逻辑学、形式逻辑、自然语言逻辑、逻辑模块、逻辑素养。
*   **替代原则**：统一使用 **“思理”**（思维的道理、思考的规律）或 **“思理学”**。
*   **具体替换**：
    *   逻辑学 / 形式逻辑 $\rightarrow$ **思理学 / 形式思理**
    *   自然语言逻辑 $\rightarrow$ **自然语言思理**
    *   逻辑模块 $\rightarrow$ **思理模块**
    *   逻辑素养 $\rightarrow$ **思理素养**
*   **理由**：“思理”是我们项目确立的本土化、准确对应“思考之理”的学科名称，足以涵盖从数学的严密推导到语文的自然语言说理。

### 2. 指代“思维活动或推理过程”
*   **滥用表现**：逻辑推理、逻辑推导、逻辑链条、逻辑论证。
*   **替代原则**：**直接删除“逻辑”二字**，或替换为 **“说理”**、**“推理”**。因为“推理”本身就是思理活动，加上“逻辑”纯属脱裤子放屁。
*   **具体替换**：
    *   逻辑推理 $\rightarrow$ **推理**（或“思理推导”）
    *   逻辑推导 $\rightarrow$ **推导**
    *   逻辑链条 $\rightarrow$ **推理链条**（或“说理脉络”）
    *   逻辑论证 $\rightarrow$ **说理论证**（或直接称 **“论证”**，以对应“修辞论辩”）
*   **理由**：消除冗余，还原动作本身。

### 3. 指代“事物或文本的内在条理、结构、关联”
*   **滥用表现**：逻辑关系、逻辑结构、逻辑顺序、内在逻辑、文章的逻辑。
*   **替代原则**：使用中文原生的结构词汇，如 **“条理”**、**“脉络”**、**“理路”**、**“关联”**、**“结构”**。
*   **具体替换**：
    *   逻辑关系 $\rightarrow$ **关联 / 条理关系 / 事理关联**
    *   逻辑结构 $\rightarrow$ **篇章结构 / 说理骨架**
    *   逻辑顺序 $\rightarrow$ **事理顺序 / 条理**
    *   内在逻辑 $\rightarrow$ **内在理路 / 内在脉络**
    *   文章的逻辑 $\rightarrow$ **文章的思路 / 文理**
    *   行文逻辑  $\rightarrow$ **行文思路 / 行文思理**
    *   情感的逻辑 $\rightarrow$ **情感的脉络 / 情感的内在理路**
*   **理由**：用“脉络”“理路”等词，能更精准地描绘出文章或情感如植物般生长、延展的有机结构，比冷冰冰的“逻辑”更有汉语的质感。

### 4. 指代“论证的合理性、说服力、严密性”（装腔作势重灾区）
*   **滥用表现**：逻辑上的力量、逻辑必然性、逻辑严密、合乎逻辑、不合逻辑、逻辑上站得住脚。
*   **替代原则**：使用描述事物客观属性的具体词汇，如 **“道理”**、**“事理”**、**“严密”**、**“说服力”**、**“必然性”**。
*   **具体替换**：
    *   逻辑上的力量 $\rightarrow$ **（理由）的份量**
    *   逻辑上的力量很强 $\rightarrow$ **很有道理 / 不容置疑**
    *   逻辑必然性 $\rightarrow$ **充分性 / 合理性 / 合乎道理**
    *   有逻辑必然性 $\rightarrow$ **合乎道理 / 必然**
    *   逻辑严密 $\rightarrow$ **推理严密 / 思维严密**
    *   合乎逻辑 / 不合逻辑 $\rightarrow$ **合乎道理（事理） / 不合道理（事理）**
    *   逻辑上站得住脚 $\rightarrow$ **道理上站得住脚 / 经得起推敲**
*   **理由**：拒绝用“逻辑”作为万能形容词。一个论证有力量，是因为它“合乎事理”、“说理严密”，而不是因为它“很逻辑”。遇到这种表达时，首先思考“它在整句话中想表达什么含义？”“是否陷入了欧化中文的陷阱，即随便用带有性、化的概括词来表达，而不是直接寻找有同样含义的具体的词”。

### 5. 指代“思维或论证中的错误”
*   **滥用表现**：逻辑谬误、逻辑漏洞、逻辑错误。
*   **替代原则**：使用 **“思维”** 或 **“思理”**。因为很多所谓的“逻辑谬误”（如诉诸情感、稻草人、滑坡）并非形式推导的错误，而是人类认知、心理或论证策略的失误。
*   **具体替换**：
    *   逻辑谬误 $\rightarrow$ **思维谬误**（或“思理谬误”）
    *   逻辑漏洞 $\rightarrow$ **思维漏洞 / 说理漏洞 / 论证破绽**
    *   逻辑错误 $\rightarrow$ **思维错误 / 推理错误**
*   **理由**：“思维谬误”更准确地涵盖了形式推导错误和非形式的认知/心理偏差。

### 6. 二元对立语境中的“逻辑”（证与辩的对立）
*   **滥用表现**：逻辑与修辞、逻辑证明 vs 情感煽动。
*   **替代原则**：在“证”与“辩”的二元框架下，使用 **“说理”**、**“思理”** 或直接使用 **“证”** 来对举“修辞”与“辩”。
*   **具体替换**：
    *   逻辑与修辞 $\rightarrow$ **思理与修辞**（或“说理与修辞”）
    *   逻辑证明 $\rightarrow$ **证明**
    *   逻辑论证 vs 修辞论辩 $\rightarrow$ **说理论证 vs 修辞论辩**（或简称为 **“证”与“辩”**）
*   **理由**：确立“证（依靠事实与思理）”与“辩（依靠修辞与心理）”的本土化二元对立框架。

## “去逻辑化”三问自检法

在遇到“逻辑”二字时，可以进行以下**三问自检**：

1.  **一问：它是不是指代一门学科或底层规律？**
    *   *如果是* $\rightarrow$ 替换为 **“思理”**。（例：自然语言思理、思理素养）
2.  **二问：它是不是在修饰“推理、推导、论证”等本身就包含思考意味的词？**
    *   *如果是* $\rightarrow$ **直接删除**。（例：逻辑推理 $\rightarrow$ 推理、逻辑证明 $\rightarrow$ 证明）
3.  **三问：它是不是在形容一个东西“有道理、严密、有说服力、有条理”？**
    *   *如果是* $\rightarrow$ 替换为具体的中文词汇：**道理、事理、脉络、理路、严密、份量**。（例：说理的份量、内在理路、合乎事理）

## 总结

彻底抛弃“逻辑”这个被滥用的外来词，不仅是为了语言的纯洁性，更是为了**夺回汉语对“思考、说理、结构”的本土定义权**。用“思理”统摄规律，用“推理”描述过程，用“道理/事理”衡量对错，用“脉络/理路”勾勒结构，用“证与辩”区分手段。
